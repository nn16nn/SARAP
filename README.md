# SARAP — акция талдау қосымшасы

Тикер енгізесіз, ол мыналарды көрсетеді: баға графигі, қысқаша қорытынды, талдаушылардың мақсатты бағасы, өсу ықтималдығы калькуляторы, көрсеткіштер, SARAP бағасы (0–100), серіктес акциялар және жаңалықтар.

## Render-ге шығару
1. GitHub-та жаңа репо ашыңыз (мысалы, `nn16nn/SARAP`) және осы папканың ішіндегі файлдарды жүктеңіз.
2. Render-де New → Blueprint (немесе Web Service) басып, репоны таңдаңыз. `render.yaml` баптауды өзі жасайды.
3. Дайын болған соң `https://<атауы>.onrender.com` сілтемесін ашыңыз. Телефонда "Басты экранға қосу" батырмасын бассаңыз, қосымша сияқты ашылады.

## Жергілікті іске қосу
```
pip install -r requirements.txt
python app.py   # http://localhost:5000
```

Деректер Yahoo Finance-тен (yfinance) алынады. Бұл қаржылық кеңес емес.
